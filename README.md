## Проверка ввода

Все данные вводятся построчно через функции `ReadInt`, `ReadInts` и `ReadWords`. Они читают всю строку и разбивают ее на значения по пробелам. Если строка не подходит, программа пишет причину ошибки и просит ввести строку заново.

- `ReadInt` принимает строку, только если в ней одно целое число из допустимого диапазона.
- `ReadInts` принимает строку, если все значения в ней целые числа, их не меньше заданного количества и их количество делится на заданное число.

# Задание 3. Удаление элементов

## Задача 10. Перестановка с концов списка

### Текст задачи

Дан список L с элементами A1, A2, A3, …, AN−1, AN (N — четное). Изменить порядок элементов в списке на следующий: AN, A1, AN−1, A2, AN−2, …, AN/2, AN/2−1. Для этого использовать два итератора i и r, связав их с первым и последним элементом списка. В цикле, который должен повторяться N/2 раз, вызывать функцию-член splice с первым параметром i++ и третьим параметром r--.

### Алгоритм решения

Итератор `i` связывается с первым элементом списка, `r` с последним. Цикл выполняется N/2 раз, на каждом шаге вызывается `l.splice(i++, l, r--)`: элемент, на который указывал `r`, переносится перед элементом, на который указывал `i`. Постфиксные `i++` и `r--` сдвигают итераторы до переноса, поэтому после шага `i` указывает на следующий элемент с начала, а `r` на следующий элемент с конца. `splice` не копирует элементы и не делает итераторы недействительными. Количество чисел должно быть четным и не меньше 2.

## Задача 2. Буквы соседних слов

### Текст задачи

Определить количество повторений каждого числа в векторе V и вывести все различные элементы вектора V вместе с количеством их повторений (в порядке возрастания значений элементов); количество повторений выводить сразу после значения соответствующего элемента. Использовать вспомогательное отображение M (класс map), ключами которого являются различные элементы вектора V, а значениями — количество повторений этих элементов. При заполнении отображения M не использовать условные конструкции (достаточно операций индексирования [] и инкремента). Элементы вектора V (при заполнении отображения M) и элементы отображения M (при выводе полученных результатов) перебирать в цикле с параметром-итератором соответствующего контейнера.

### Алгоритм решения

Вектор перебирается в цикле с итератором, для каждого элемента выполняется `++m[*it]`. Если такого ключа еще нет, оператор `[]` создает его со значением 0, поэтому условия не нужны. `map` хранит ключи по возрастанию, и цикл с итератором по `m` выводит каждый элемент и количество его повторений. Вектор должен содержать хотя бы один элемент.
