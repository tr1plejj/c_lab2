# ФИО, группа. Лабораторная работа №2. Вариант 1

Каждое задание находится в своей паре файлов `taskN.h` и `taskN.cpp`. Функции ввода с проверкой находятся в `io_utils.h` и `io_utils.cpp`, меню в `main.cpp`.

Сборка и запуск:

```
g++ -std=c++17 -o lab2 main.cpp io_utils.cpp task*.cpp
./lab2
```

После запуска выводится меню. Задание выбирается номером от 1 до 10, для выхода нужно ввести 0.

## Проверка ввода

Все данные вводятся построчно через функции `ReadInt`, `ReadInts` и `ReadWords`. Они читают всю строку и разбивают ее на значения по пробелам. Если строка не подходит, программа пишет причину ошибки и просит ввести строку заново.

- `ReadInt` принимает строку, только если в ней одно целое число из допустимого диапазона.
- `ReadInts` принимает строку, если все значения в ней целые числа, их не меньше заданного количества и их количество делится на заданное число.
- `ReadWords` принимает строку, если все слова состоят только из латинских букв и их не меньше заданного количества.

Числа разбираются функцией `std::from_chars`, поэтому значения вида `12abc`, `0.5`, `+5` и числа за пределами типа `int` не принимаются. При конце ввода (Ctrl+D) программа завершается. Ограничения отдельных задач описаны в самих задачах.

## Задача 3. Половины вектора

### Текст задачи

Дан набор целых чисел с четным количеством элементов. Заполнить вектор V исходными числами, вывести вначале вторую половину элементов вектора V, а затем первую половину (в каждой половине порядок элементов не изменять).

### Алгоритм решения

Вектор V создается конструктором из пары итераторов исходного набора. Итератор `middle = begin() + size() / 2` указывает на начало второй половины. Первый цикл с итератором выводит элементы от `middle` до `end()`, второй от `begin()` до `middle`. Количество чисел должно быть четным и не меньше 2.

### Тестирование

```
Введите чётное количество целых чисел: 1 2 3
Ошибка: количество чисел должно делиться на 2.
Введите чётное количество целых чисел: 1 2 x 4
Ошибка: "x" не является целым числом (int).
Введите чётное количество целых чисел: 1 2 3 4 5 6
Вектор V: 1 2 3 4 5 6
Результат: 4 5 6 1 2 3
```

## Задача 3. Первая треть в конец списка

### Текст задачи

Дан список L, количество элементов которого делится на 3. Добавить в конец списка первую треть его исходных элементов в обратном порядке. Использовать один вызов функции-члена insert.

### Алгоритм решения

Список L создается конструктором из пары итераторов. Функция `std::next` находит итератор `third_end` на первый элемент после первой трети. Обратный итератор `make_reverse_iterator(third_end)` указывает на последний элемент первой трети, `rend()` на позицию перед первым элементом. Вызов `insert(end(), make_reverse_iterator(third_end), rend())` добавляет в конец списка элементы первой трети от последнего к первому. Количество чисел должно делиться на 3 и быть не меньше 3.

### Тестирование

```
Введите целые числа (количество кратно 3): 1 2 3 4
Ошибка: количество чисел должно делиться на 3.
Введите целые числа (количество кратно 3):
Ошибка: нужно не меньше 3 чисел.
Введите целые числа (количество кратно 3): 1 2 3 4 5 6 7 8 9
Исходный список L: 1 2 3 4 5 6 7 8 9

```

# Задание 3. Удаление элементов

## Задача 10. Перестановка с концов списка

### Текст задачи

Дан список L с элементами A1, A2, A3, …, AN−1, AN (N — четное). Изменить порядок элементов в списке на следующий: AN, A1, AN−1, A2, AN−2, …, AN/2, AN/2−1. Для этого использовать два итератора i и r, связав их с первым и последним элементом списка. В цикле, который должен повторяться N/2 раз, вызывать функцию-член splice с первым параметром i++ и третьим параметром r--.

### Алгоритм решения

Итератор `i` связывается с первым элементом списка, `r` с последним. Цикл выполняется N/2 раз, на каждом шаге вызывается `l.splice(i++, l, r--)`: элемент, на который указывал `r`, переносится перед элементом, на который указывал `i`. Постфиксные `i++` и `r--` сдвигают итераторы до переноса, поэтому после шага `i` указывает на следующий элемент с начала, а `r` на следующий элемент с конца. `splice` не копирует элементы и не делает итераторы недействительными. Количество чисел должно быть четным и не меньше 2.

### Тестирование

```
Введите чётное количество целых чисел: 1 2 3 4 5
Ошибка: количество чисел должно делиться на 2.
Введите чётное количество целых чисел: 1 2 3 4 5 6
Исходный список L: 1 2 3 4 5 6
Результат: 6 1 5 2 4 3
```

## Задача 5. Замена цифр

### Текст задачи

Дан набор символов. Вывести все символы из исходного набора в том же порядке, заменяя цифровые символы на символ подчеркивания. Использовать алгоритм replace_copy_if.

### Алгоритм решения

Введенная строка помещается в поток `istringstream`. Флаг `noskipws` нужен, чтобы `istream_iterator<char>` не пропускал пробелы. Алгоритм `replace_copy_if` копирует символы из `istream_iterator<char>` в `ostream_iterator<char>` и заменяет на `'_'` символы, для которых лямбда-выражение с `isdigit` возвращает true. Пустая строка не принимается.

### Тестирование

```
Введите набор символов:
Ошибка: набор пуст. Введите хотя бы один символ: a1b2 c3! 2026 year
Результат: a_b_ c_! ____ year
```

## Задача 1. Второй ноль

### Текст задачи

Дан вектор V. Удалить второй из элементов вектора, равных нулю. Если нулевых элементов меньше двух, то вектор не изменять. Использовать два вызова алгоритма find и функцию-член erase.

### Алгоритм решения

Первый вызов `find` ищет первый ноль во всем векторе. Если нуля нет, вектор не меняется. Иначе второй вызов `find` ищет ноль начиная со следующего элемента. Если второй ноль найден, он удаляется через `erase`. Вектор должен содержать хотя бы один элемент.

### Тестирование

```
Введите элементы вектора V: 1 0 2 0 3 0
Исходный вектор V: 1 0 2 0 3 0
Результат: 1 0 2 3 0
```

```

Исходный вектор V: 4 0 7
Результат: 4 0 7
```

## Задача 11. Сортировка слов по длине

### Текст задачи

Дан дек D, элементами которого являются английские слова. Отсортировать его элементы по убыванию их длин, а элементы одинаковой длины — в алфавитном порядке. Использовать единственный вызов алгоритма sort с параметром — функциональным объектом, включающим как сравнение строк, так и сравнение их длин.

Дек D создается конструктором из пары итераторов. `sort` вызывается один раз с лямбда-выражением: если длины слов различаются, раньше идет более длинное слово, иначе слова сравниваются оператором `<`. Строки сравниваются по кодам символов, поэтому заглавные буквы идут раньше строчных. Нужно хотя бы одно слово из латинских букв.


# Задание 8. Численные алгоритмы

## Задача 2. Буквы соседних слов

### Текст задачи

Дан список L, элементами которого являются английские слова. Получить дек D со строковыми элементами, каждый из которых строится по паре соседних элементов исходного списка L следующим образом: последняя буква правого элемента пары приписывается справа к первой букве левого элемента пары. Количество элементов дека D должно быть на 1 меньше количества элементов списка L. Например, для исходного списка ABC, DEF, KLM, XYZ полученный дек должен содержать строки AF, DM, KZ. Использовать алгоритм adjacent_difference с итератором вставки и функциональным объектом, а также функцию-член erase для дека D.

### Алгоритм решения

`adjacent_difference` записывает результаты в дек D через `back_inserter`. Для каждой пары соседних слов вызывается лямбда-выражение с аргументами (текущее слово, предыдущее слово). Оно возвращает строку из первой буквы предыдущего слова и последней буквы текущего. Первым элементом `adjacent_difference` записывает копию первого слова, поэтому он удаляется через `erase(begin())`. Нужно не меньше 2 слов из латинских букв.

### Тестирование

```
Введите английские слова (не менее 2): ABC
Ошибка: нужно не меньше 2 слов.
Введите английские слова (не менее 2): ABC DEF KLM XYZ
Исходный список L: ABC DEF KLM XYZ
Дек D: AF DM KZ
```

# Задание 9. Множества

## Задача 1. Векторы, содержащие V0

### Текст задачи

Дан вектор V0, целое число N (> 0) и набор векторов V1, …, VN. Известно, что размер вектора V0 не превосходит размера любого из векторов V1, …, VN. Найти количество векторов VI, I = 1, …, N, в которых содержатся все элементы вектора V0 (без учета их повторений). Использовать алгоритм includes, применяя его в цикле к двум множествам, одно из которых создано на основе вектора V0, а другое на очередной итерации содержит элементы очередного из векторов VI, I = 1, …, N.

### Алгоритм решения

Из V0 создается множество `required`. Векторы V1…VN перебираются в цикле с итератором, из каждого создается множество `current`. `includes` проверяет, что все элементы `required` есть в `current`, и в этом случае счетчик увеличивается. Множество хранит каждое значение один раз, поэтому повторения не учитываются. V0 должен содержать хотя бы один элемент, N вводится от 1 до 100, каждый VI должен содержать не меньше элементов, чем V0.

### Тестирование

```
Введите элементы V0: 1 2 2
Введите N (от 1 до 100): 0
Ошибка: нужно одно целое число от 1 до 100.
Введите N (от 1 до 100): 3
Введите элементы V1 (не менее 3): 1
Ошибка: нужно не меньше 3 чисел.
Введите элементы V1 (не менее 3): 2 1 5
Введите элементы V2 (не менее 3): 1 3 4
Введите элементы V3 (не менее 3): 2 2 1
Векторов, содержащих все элементы V0: 2
```

# Задание 10. Отображения

## Задача 1. Количество повторений

### Текст задачи

Дан вектор V. Определить количество повторений каждого числа в векторе V и вывести все различные элементы вектора V вместе с количеством их повторений (в порядке возрастания значений элементов); количество повторений выводить сразу после значения соответствующего элемента. Использовать вспомогательное отображение M (класс map), ключами которого являются различные элементы вектора V, а значениями — количество повторений этих элементов. При заполнении отображения M не использовать условные конструкции (достаточно операций индексирования [] и инкремента). Элементы вектора V (при заполнении отображения M) и элементы отображения M (при выводе полученных результатов) перебирать в цикле с параметром-итератором соответствующего контейнера.

### Алгоритм решения

Вектор перебирается в цикле с итератором, для каждого элемента выполняется `++m[*it]`. Если такого ключа еще нет, оператор `[]` создает его со значением 0, поэтому условия не нужны. `map` хранит ключи по возрастанию, и цикл с итератором по `m` выводит каждый элемент и количество его повторений. Вектор должен содержать хотя бы один элемент.

### Тестирование

```
Введите элементы вектора V: 1 2 3e
Ошибка: "3e" не является целым числом (int).
Введите элементы вектора V: 5 -1 5 3 -1 5
Элемент и количество повторений:
-1 2
3 1
5 3
```
